# Dataset

FoodPulse uses a publicly distributed Zomato food-delivery operations dataset.

The dataset contains 45,584 records and 20 raw attributes and includes
information related to delivery partners, locations, order timing,
weather, traffic, vehicle characteristics, city, and delivery duration.

The raw CSV is not stored in this repository. The FoodPulse application
and analytical notebook retrieve the dataset from the configured public
source and verify the expected dataset shape before processing.

Dataset provenance:
Varunnagar/Zomato-Food-Delivery-Analysis

The dataset is used for academic analysis and is not an official internal
Zomato production database.
